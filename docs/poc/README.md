# 0단계 기술 검증

본 제작에 들어가기 전에, 실패하면 설계를 바꿔야 하는 부분을 윈도우와 맥에서 각각 먼저 확인한다. 두 OS 모두 통과해야 1단계로 간다. (계획서 `docs/PLAN.md` 13장)

## 진행 현황

| # | 항목 | 확인 방법 | 맥 | 윈도우 |
|---|---|---|---|---|
| 1 | 한글·PPT·엑셀 창 찾기 → 앞으로 → 배치 → 닫기 | 실행기 F1~F3, P2, P5, P6 | 손쉬운 사용 권한 대기 | 시작 전 |
| 2 | 브라우저 새 창 열기와 추적 (크롬·엣지·웨일) | 실행기 B1 | 손쉬운 사용 권한 대기 | 시작 전 |
| 3 | 듀얼 모니터 (학생 화면으로 옮기기, 배율, 연결 끊김) | 실행기 P1, P3, P4 + 손으로 연결 끊기 | 모니터 인식 통과, 창 옮기기는 권한 대기 | 시작 전 |
| 4 | PPT 슬라이드 쇼 위에 사이드바·도구 표시 | 작은 Electron 시험 앱 (만들 예정) | 시작 전 | 시작 전 |
| 5 | 60분 연속 녹화 | Electron 시험 앱 (만들 예정) | 시작 전 | 시작 전 |
| 6 | 구글 드라이브 폴더 윈도우 ↔ 맥 왕복 | 손으로 하는 절차 (만들 예정) | 시작 전 | 시작 전 |
| 7 | 학교 PC에서 실행 | 설치 없이 실행 버전 | 해당 없음 | 시작 전 |

OS별 자세한 결과: `mac.md`, `windows.md`

## 실행 방법
```bash
cd poc
npm test                                         # 공통 로직 단위 테스트
npm run build:mac                                # 맥만: 도우미 빌드
node runner/run.js --browsers=chrome,edge,whale  # 기술 검증 실행
```
- 실행기는 **자기가 연 창만** 옮기고 닫는다. 실행 중에는 프로그램 창이 저절로 열리고 움직이니 다른 작업을 잠시 멈춘다.
- 결과는 화면에 표로 나오고, 자세한 값은 `poc/out/report-*.json`에 남는다 (저장소에는 올리지 않음).
- 결과 표를 `mac.md` / `windows.md`에 옮겨 적고, 실패한 항목은 원인과 다음 시도를 함께 적는다.

## 시험 자료 (`poc/samples/`)
- `page-a.html`, `page-b.html`: 브라우저 새 창 시험용 로컬 페이지
- `샘플_발표자료.pptx`, `샘플_모둠편성.xlsx`: `make_samples.py`로 만든 가짜 내용 (학생 정보 없음)
- 한글 파일: 아직 없음. 내용 없는 `.hwp` 또는 `.hwpx` 하나를 넣으면 실행기가 그 파일로 시험한다. 없으면 한글을 빈 문서로 열어 시험한다.
