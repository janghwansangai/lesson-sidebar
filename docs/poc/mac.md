# 기술 검증 결과 — 맥

## 시험 환경 (2026-11-21)
- MacBook (Apple Silicon), macOS 27.2.1, Node 24.14, Swift 6.4
- 모니터: 내장 Retina 1512×982 포인트(배율 2, 주 모니터) + 외부 MB16NCG 1280×800 포인트(배율 2, 내장 화면 왼쪽)
- 설치된 프로그램: 한컴오피스 HWP, Microsoft PowerPoint·Excel, 크롬, 엣지, 웨일

## 1차 실행 (2026-11-21)

| 항목 | 결과 | 내용 |
|---|---|---|
| 공통 로직 단위 테스트 | 통과 | 8개 모두 통과 (한글 NFC/NFD 짝짓기, 새 창 고르기, 학생 화면 추정, 분할 계산) |
| 맥 도우미 빌드 | 통과 | `swift build -c release` 성공 |
| P0 창 제어 권한 | **실패** | 이 맥에서 Claude에 "손쉬운 사용" 권한이 없음 → 창 시험 전부 대기 |
| P1 모니터 목록 | 통과 | 2개 인식. 외부 모니터가 x = -1280(왼쪽)에 있어 음수 좌표도 정상. 학생 화면 추정: MB16NCG |

### 알게 된 것
- 외부 모니터의 사용 가능 영역에 메뉴 막대가 빠져 있다(높이 800 그대로). 이 맥은 "디스플레이마다 별도 공간 사용"이 꺼져 있는 것으로 보인다. 전체 화면 슬라이드 쇼 동작이 이 설정에 따라 달라지므로 항목 4에서 두 설정 모두 시험한다.
- 명령줄 도우미가 받는 권한은 **Claude 앱**의 권한이다. 실제 앱(수업 사이드바)은 설치 후 자기 이름으로 권한을 따로 받는다.
