## 알게 된 것 (설계에 반영)

1. **브라우저는 LaunchServices(`open -na <앱> --args --new-window <주소>`)로 연다.** 실행 파일을 직접 부르면 부른 프로그램의 제한을 물려받는다. 이번에는 시험 환경의 제한 때문에 엣지가 자기 설정 폴더를 만들지 못하고 바로 꺼졌다. `open`으로 열면 독립된 프로그램으로 실행되어 문제가 없다.
2. **로컬 파일을 `file://`로 브라우저에 넘기면 안 된다.** 엣지가 바탕화면 폴더의 시험 파일을 열려다 macOS의 "데스크탑 폴더의 파일에 접근하려고 합니다" 권한 창을 띄웠고, 답하기 전까지 빈 창이 됐다. 수업 중에 이런 창이 뜨면 곤란하다. 사이드바가 `127.0.0.1` 주소(무작위 토큰 포함, 수업 폴더만)로 파일을 제공하니 권한 창 없이 바로 열렸다. 학교 관리 브라우저가 `file://`을 막는 경우도 피할 수 있다.
3. **외부 모니터에도 메뉴 막대(30포인트)가 있는데 macOS가 사용 영역에서 빼 주지 않는다.** 그래서 창이 30포인트 아래로 밀렸다. 화면마다 떠 있는 메뉴 막대 창의 위치를 직접 읽어 사용 영역에서 빼도록 도우미를 고쳤다 (내장 33, 외부 30). "디스플레이마다 별도 공간 사용"이 꺼져 있어도 메뉴 막대가 보이는 상태였다.
4. **프로그램마다 최소 폭이 있다.** 크롬·엣지·웨일은 500포인트보다 좁아지지 않는다. 1280 폭 학생 화면에서 7:3을 고르면 오른쪽이 384가 되어 창이 겹친다. 조절 바와 배치 버튼은 최소 폭에서 멈추도록 비율을 조정한다 (`fitRatio`).
5. **프로그램에 확인·로그인 창(모달)이 떠 있으면 창 닫기 요청이 무시된다.** 엣지에 학교 Microsoft 계정 로그인 창이 떠 있어 다른 창이 닫히지 않았다. 사이드바는 "이 프로그램에 답을 기다리는 창이 있습니다"를 표시하고 그 창을 앞으로 가져와야 한다. 저장 여부를 묻는 창도 같다.
6. **브라우저 창 제목에 사용자 프로필 이름이 붙는다** (예: "… - Chrome - (프로필 이름)"). 창 제목을 공유 파일이나 기록에 남기지 않는다. 시험 결과 파일(`poc/out/`)은 저장소에 올리지 않는다.
7. 오피스 창 제목은 확장자 없는 파일 이름이다 ("샘플_발표자료"). 한글 파일 이름도 NFC/NFD 차이 없이 짝이 맞았다.

### 체험판에서 새로 알게 된 것
8. **최소화된 창은 접근성 정보에서 종류가 "대화상자(AXDialog)"로 바뀐다.** 그래서 처음에는 최소화된 PPT·메모 창이 목록에서 사라져 "닫힘"으로 잘못 표시됐다. 최소화된 창은 대화상자여도 목록에 넣도록 도우미를 고쳤다.
9. 맥이 한국어일 때 프로그램 이름이 한국어로 나온다 (텍스트 편집기, 한컴오피스 한글). 창 찾기는 프로그램 이름 또는 번들 ID(com.apple.TextEdit 등)로 하므로 문제없다.
10. 앞으로 가져오기가 기술 검증(0.16초)보다 느린 0.7초인 것은 화면 요청 → 도우미 실행 → 맨 앞 확인을 거치기 때문이다. 1단계에서 도우미를 계속 켜 두고 명령을 주고받는 방식으로 줄인다.

## 수업 준비 화면 (2026-11-22, `app/`)
원격 조작으로 실제 실행해 확인: 보관함 만들기 → 새 수업 → 파일 4개 복사·링크·메모 → 순서 바꾸기·이름 바꾸기·빼기 → 정리하기(파일 이름이 새 순서를 따름) → 이 수업으로 진행 → 사이드바에서 PPT 열기 2.2초 → 다른 곳에서 lesson.json을 고치자 3초 안에 준비 화면·사이드바 모두 반영 (열린 PPT 연결 유지).

11. **잠금 파일은 PC마다 따로 써야 한다.** 처음에는 `.sidebar/lock.json` 하나에 번갈아 써서, 이 맥이 쓰는 순간 다른 PC의 표시가 지워졌다. `.sidebar/locks/<PC 이름>.json`으로 바꾸자 경고가 계속 보이고, 이 맥이 끝날 때 자기 기록만 지운다.
12. 넣은 파일 중 `.py` 같은 스크립트는 기본 프로그램으로 열면 실행될 수 있어 거른다.

## 답을 기다리는 창 — 저장 확인 창이 떠 있을 때 닫기 (4차, 2026-11-21)
`node runner/modal.js`(엑셀) · `node runner/modal.js --app=hwp`(한글). 예시 파일을 `poc/out/`에 새 이름으로 복사해 열고, 글자 하나를 넣은 뒤 닫기 요청을 보낸다. 선생님이 열어 둔 엑셀·한글 창은 건드리지 않았다. 외부 모니터 없이 맥 화면 하나로. 체험판(`app/`)도 실제로 띄워 같은 순서로 확인했다 (개발용 원격 조작, 임시 수업 폴더).

| 항목 | 엑셀 | 한글 |
|---|---|---|
| 저장 확인 창의 모양 | 창에 붙은 **시트** (창의 자식, 역할 `AXSheet`) | 프로그램 전체를 막는 **모달 대화상자** (하위 역할 `AXDialog`, `AXModal` 참) |
| 닫기 요청 뒤 `list`의 `waiting`에 보이기까지 | 0.7초 | 0.7초 (닫기 호출 자체가 2.1초 걸림, 아래 19) |
| 저장 창이 떠 있는 동안 바탕 창의 닫기 단추 | 사용 안 함 | **그대로 눌림** |
| 닫기 요청 한 번 더 | 무시됨 | **저장 창이 하나 더 생김** (아래 20) |
| 앞으로 가져오기(`raise`) | 성공 0.17초, 시트가 함께 앞으로 | 성공 0.21초, 도우미가 대화상자에 포커스를 줌 |

| 체험판: 답한 뒤 | "저장" → 목록이 닫힘으로 | "취소" 뒤 목록을 누르면 다시 열림으로, "저장" → 닫힘으로 |

17. **맥의 답을 기다리는 창은 두 가지 모양이다.** 창에 붙는 시트(엑셀)와 프로그램 전체를 막는 모달 대화상자(한글, 엣지 로그인 창). 도우미 `list`가 창마다 `waiting`으로 알려 준다 (규격 `helper-protocol.md`). 모달 대화상자는 프로그램 전체를 막으므로 그 프로그램의 모든 창에 같은 `waiting`이 나온다. 최소화된 창도 하위 역할이 `AXDialog`이지만(→ 8) `AXModal`·최소화 여부로 구분된다.
18. **시트가 붙으면 프로그램의 "포커스 창"이 시트로 바뀐다.** 그래서 `front`가 시트 번호를 알려, 앞으로 가져오기가 1.5초를 기다린 뒤 실패로 판단했다. `front`가 바탕 창 번호 + `dialog`(시트)로 알리게 고쳤다 (윈도우 도우미와 같은 모양).
19. 한글은 바뀐 문서의 닫기 단추를 누르면 저장 창을 띄우느라 2.1초 뒤에 접근성 오류(-25204, 완료하지 못함)로 답한다. 요청은 전달됐으므로, 도우미는 창이 닫혔거나 `waiting`이 생겼으면 `ok: true`로 알린다. 바뀌지 않은 문서는 0.9초에 정상으로 닫힌다.
20. **한글은 저장 창이 떠 있어도 닫기 단추가 눌린다. 닫기를 또 보내면 저장 창이 하나 더 생기고, 그 창은 문서가 저장·닫힌 뒤에도 남아 선생님이 원래 열어 둔 한글 창까지 막았다.** (시험 도구가 만든 창이라 바로 "취소"로 치웠다.) → 체험판은 `waiting`이 있으면 닫기 요청을 보내지 않고 그 창을 앞으로 가져온다. 시험 도구는 정리할 때 대화상자를 모두 취소 → 닫기 한 번 → 저장 순서로 한다.
21. 한글은 바탕 창을 앞으로 가져오면(주 창으로 지정) 포커스가 대화상자에서 바탕 창으로 옮겨 간다. 도우미 `raise`가 이어서 대화상자에 포커스를 준다. 한글 대화상자는 화면 창 목록(CGWindow)의 "화면에 있음" 값이 처음부터 거짓이라 판단에 쓰지 않는다.
22. 지금 이 맥의 엣지에 모달 대화상자(로그인 창으로 보임)가 떠 있어 엣지 창 6개 모두 `waiting`이 나온다. 기록 5에서 엣지 창이 닫히지 않은 이유와 맞는다. 다른 프로그램(크롬·파워포인트·텍스트 편집기 등)은 `null`.
23. 한글의 말풍선 도움말(`AXHelpTag`)은 하위 역할이 없어 일반 창으로 목록에 섞여 들어왔다. 역할이 `AXWindow`인 것만 넣도록 고쳤다.
24. `list`는 창 28개에서 0.61초 → 0.66초 (창마다 시트 확인이 늘어남).
25. 시험 도구의 글자 입력은 `osascript`(JavaScript)로 키보드 이벤트를 보낸다. 손쉬운 사용 권한만 쓰고 "자동화" 권한 창은 뜨지 않았다. 키는 시험 창(또는 그 대화상자)이 맨 앞일 때만 보낸다. 시험 결과에 창 제목은 출력하지 않는다.
26. 텍스트 편집기는 시험하지 않았다 (엑셀·한글로 두 가지 모양을 모두 확인).
