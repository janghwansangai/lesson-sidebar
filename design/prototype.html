      검토 결론
      
        
      차선책이던 사이드바 방식을 기본 구조로 정합니다
      
        
      자료를 보여주는 일은 한글·파워포인트·크롬처럼 오래 검증된 프로그램에 맡기고, 수업 사이드바는 열기·찾기·앞으로·배치·닫기만 합니다. 우리가 만드는 코드가 적을수록 수업 중 사고도 적습니다. 프로그램은 설치형 하나이며 확장 프로그램은 없습니다. 수업은 폴더 하나로 관리합니다. 이 폴더를 구글 드라이브 데스크톱 폴더에 두면 윈도우에서 준비하다가 맥에서 이어서 편집할 수 있고, 클라우드를 못 쓰는 PC는 꾸러미(.zip)로 오갑니다.
      
        
        
          
      • 고장 범위가 작다한 프로그램이 멈춰도 그 창만 멈춥니다. 사이드바와 나머지 자료는 그대로입니다.
        • 
          
      • 표시 품질이 원래 그대로다PPT 애니메이션, 한글 서식, 구글·캔바 로그인이 평소와 똑같이 동작합니다.
        • 
          
      • 원래 문제를 정확히 푼다창이 몇 개든 사이드바 하나가 리모컨이 되어, 수업 중 창을 찾느라 시간을 쓰지 않습니다.
        • 
        
      
      
      

      
      
        
      두 방식 비교
      
        
      
          
      기준한 창 통합형 (v0.1)수업 사이드바형 (채택)
      
          
            
      자료를 보여주는 곳우리 앱이 웹·PDF·미디어·문서 변환을 모두 처리한글·파워포인트·엑셀·브라우저 등 원래 프로그램
      
            
      표시 품질PPT 애니메이션, 한글 서식 재현 불가원래 그대로
      
            
      구글·캔바 로그인내장 브라우저 로그인이 막힐 위험평소 쓰는 브라우저 그대로
      
            
      하나가 멈추면앱 전체가 흔들릴 수 있음그 프로그램만 멈춤
      
            
      만들 양많음 (종류별 뷰어, 탭, 문서 변환)적음 (열기·찾기·앞으로·배치·닫기)
      
            
      창 전환 속도빠름미리 열어 두면 빠름, 처음 켤 때만 느림
      
            
      확대·포인터·캡처 핀·스포트라이트·녹화가능똑같이 가능 (화면 전체에 동작)
      
            
      필요 조건없음해당 프로그램 설치, 맥은 접근성 권한
      
                
        
      
      
      

      
      
        
      사이드바 방식의 약점과 보완
      
        
      
          
      약점보완
      
          
            
      처음 켤 때 느림 (PPT 3~5초)수업 시작 · 모두 미리 열기로 수업 직전에 전부 열어 두고, 수업 중 클릭은 앞으로 가져오기만 합니다 (0.3초 이내).
      
            
      다른 프로그램 창을 정확히 찾아야 함프로그램 이름 + 창 제목 속 파일 이름으로 연결합니다. 제목이 바뀌면 다시 찾고, 못 찾으면 열린 창 목록에서 직접 연결합니다.
      
            
      웹 자료가 탭이 아니라 창으로 열림사이드바로 전환하므로 창이 많아도 찾을 일이 없고, 화면 분할 때 탭을 떼어낼 필요도 없습니다. 탭 하나만 골라 닫는 기능은 없습니다 (창 단위).
      
            
      수업 PC에 프로그램이 있어야 함사전 점검에서 확인하고, 없으면 대안을 안내합니다 (한글 뷰어, PDF·그림·영상은 브라우저).
      
            
      맥은 "손쉬운 사용" 권한 필요첫 실행 때 안내 화면으로 한 번 허용합니다.
      
            
      창이 여러 개라 어수선함사이드바로만 전환, "다른 창 숨기기", 화면 분할로 정리합니다.
      
                
        
      
      
      

      
      
        
      화면 분할은 이렇게 동작합니다
      
        
      
          
      사용 흐름
        
            
      1. 사이드바에서 체크나 Ctrl/⌘+클릭으로 2~4개 선택 (닫혀 있으면 자동으로 엽니다)
        2. 
            
      2. 배치 선택: 반반 · 7:3 · 3분할 · 큰 화면+2 · 4분할
        3. 
            
      3. 고른 순서대로 왼쪽부터 배치. 듀얼 모니터면 학생 화면에, 모니터 한 대면 사이드바를 뺀 영역에 놓습니다
        4. 
            
      4. 창 경계의 조절 바를 끌면 양쪽 창 크기가 함께 바뀝니다
        5. 
            
      5. 분할 해제를 누르면 원래 위치와 크기로 돌아갑니다
        6. 
          
      
          
      구현
        
            
      • Windows: SetWindowPos로 위치·크기 지정, 최대화 창은 먼저 복원, 모니터 배율(DPI)과 창 그림자 테두리 보정
        • 
            
      • macOS: 접근성 API로 위치·크기 설정, 전체 화면 창은 먼저 해제
        • 
            
      • 웹 자료는 처음부터 각자 브라우저 창이라 그대로 배치
        • 
            
      • 조절 바는 경계에 띄운 얇은 항상 위 창
        • 
            
      • 자주 쓰는 배치는 수업 흐름에 저장해 한 번에 다시 배치
        • 
          
      
          
      주의할 점
        
            
      • PPT 전체 화면 슬라이드쇼는 반쪽에 넣을 수 없어 창 모드 슬라이드 쇼로 바꿔 배치합니다
        • 
            
      • 프로그램마다 최소 크기가 있어 조절 바는 그 이하로 끌리지 않습니다
        • 
            
      • 무거운 프로그램은 끄는 동안 안내선만 보여 주고 놓을 때 적용하는 방식도 고를 수 있게 합니다
        • 
            
      • 듀얼 모니터면 기본으로 학생 화면에 배치하고, 다른 화면을 고를 수도 있습니다
        • 
          
      
        
      
      
      

      
      
        
      듀얼 모니터: 교사 화면과 학생 화면
      
        
      노트북·교탁 모니터(교사 화면)와 프로젝터·전자칠판·TV(학생 화면)를 기본으로 생각합니다. 처음 연결할 때 학생 화면을 한 번 고르면 모니터 이름으로 기억해, 같은 교실에서는 다음부터 자동입니다.
      
        
      
          
      학생 화면에 띄우기
        
            
      • 목록에서 누르면 자료가 학생 화면에 바로 뜹니다
        • 
            
      • 진행 메모·수업 폴더는 교사 화면에 열립니다 (자료마다 바꿀 수 있음)
        • 
            
      • "교사 화면에서 먼저"로 바꾸면 내 화면에서 확인한 뒤 ⇄로 학생 화면에 보냅니다
        • 
            
      • 열린 창은 ⇄ 한 번으로 다른 화면으로 옮기고, 학생 화면에서는 꽉 차게 놓습니다
        • 
          
      
          
      학생 화면 관리
        
            
      • 미리보기: 사이드바 위쪽에 학생 화면을 작게 실시간으로 보여 줌
        • 
            
      • 정지: 지금 장면을 학생 화면에 고정해 두고 뒤에서 창 정리
        • 
            
      • 가리기: 검은 화면 + "잠시 후 계속합니다"
        • 
          
      
          
      도구와 녹화
        
            
      • 화면 분할·확대·캡처 핀: 학생 화면 기준
        • 
            
      • 포인터 강조·스포트라이트: 마우스가 있는 화면
        • 
            
      • 녹화: 학생 화면 (교사 화면·두 화면 모두로 바꿀 수 있음)
        • 
            
      • PPT 슬라이드 쇼는 학생 화면, 발표자 보기는 교사 화면 (기술 검증 대상)
        • 
          
      
          
      연결이 바뀔 때
        
            
      • 프로젝터 연결이 끊기면 창을 교사 화면으로 모으고, 다시 연결되면 돌려놓기
        • 
            
      • 화면마다 다른 배율(노트북 200%, 프로젝터 100%) 보정
        • 
            
      • 복제(미러) 모드면 사전 점검에서 알리고 자동 숨김 권장
        • 
            
      • 분할 배치는 "학생 화면 + 비율"로 저장해 교실이 바뀌어도 같은 모양
        • 
          
      
        
      
      
      

      
      
        
      앱은 도구, 수업은 폴더: 윈도우와 맥을 오가며 편집
      
        
      수업에 필요한 모든 것은 수업 폴더 안에만 저장합니다. 문서 프로그램이 파일을 열듯 수업 사이드바는 수업 폴더를 엽니다. 동기화는 구글 드라이브 데스크톱 앱이 맡으므로 사이드바는 드라이브 API·구글 로그인·토큰을 다루지 않습니다. OneDrive, Dropbox, NAS, USB도 똑같이 됩니다.
      
        
      
          
      사용 흐름
        
            
      1. 윈도우 PC와 맥에 구글 드라이브 데스크톱 앱 설치, 같은 계정 로그인
        2. 
            
      2. 사이드바 설정에서 수업 보관함 위치를 내 드라이브/수업 사이드바로 한 번 지정
        3. 
            
      3. 윈도우에서 준비하고 저장하면 폴더째 드라이브에 올라감
        4. 
            
      4. 맥의 사이드바 보관함에 같은 수업이 보이고, 열어서 이어서 편집
        5. 
          
      
          
      폴더 안 / 이 PC에만
        
            
      • 폴더 안: lesson.json(흐름·메모·시작 위치·분할 배치), 자료, 캡처, 녹화와 챕터, 수업안내.html, .sidebar/ 잠금·백업
        • 
            
      • 이 PC에만: 최근 연 폴더, 프로그램 실제 위치(윈도우 Hwp.exe / 맥 한컴오피스), 모니터 배치, 단축키, 미리보기 캐시
        • 
            
      • lesson.json에는 "한글로 열기"처럼 프로그램 종류만 적어 두 PC에서 각자 동작
        • 
          
      
          
      두 PC가 부딪히지 않게
        
            
      • 잠금 파일: "윈도우 PC에서 편집 중 · 1분 전" → 읽기 전용 / 그래도 편집
        • 
            
      • 바깥 변경 감지: 다른 PC의 저장이 도착하면 다시 불러오기
        • 
            
      • 충돌 사본(lesson (1).json)이 생기면 나란히 비교해 고르기
        • 
            
      • 원자적 저장 + 최근 10개 백업
        • 
          
      
          
      동기화가 덜 됐을 때
        
            
      • 아직 안 내려온 파일은 "동기화 기다리는 중", 도착하면 자동 반영
        • 
            
      • 스트리밍 모드 대비: 사전 점검 "수업 전에 모두 내려받기"
        • 
            
      • 녹화는 이 PC 임시 폴더에 기록한 뒤 끝나면 _녹화/로 옮김
        • 
            
      • 한글 파일 이름 NFC/NFD 차이를 같은 이름으로 취급
        • 
          
      
        
      
      
      

      
      
        
      수업 꾸러미 (.zip): 클라우드를 못 쓸 때
      
        
      
          
      내보내기
        
            
      • 파일 하나: 2026-11-28_AI활용수업설계연수_1차.zip
        • 
            
      • lesson.json, 자료 파일, 메모, 링크, 수업안내.html, 캡처, manifest.json
        • 
            
      • 녹화 영상은 용량이 커서 선택 사항
        • 
            
      • 보내기 전에 순번 정리를 자동 실행
        • 
            
      • 받는 사람 권한이 필요한 구글·캔바 링크를 미리 알려 줌
        • 
          
      
          
      가져오기
        
            
      • manifest 확인 → 파일 손상 검사(해시) → 위험한 경로·실행 파일 차단 → 압축 해제 용량 제한
        • 
            
      • 같은 수업이 있으면 사본으로 / 덮어쓰기(기존 백업) / 취소
        • 
            
      • 가져오자마자 편집 가능, 이 PC에 필요한 프로그램이 있는지 사전 점검 자동 실행
        • 
          
      
          
      PC를 옮겨도 안 깨지게
        
            
      • 파일 위치는 모두 수업 폴더 기준 상대 경로
        • 
            
      • 맥의 한글 파일 이름(자모 분리 NFD)을 NFC로 바꾸고 zip UTF-8 표시를 켜서 Windows에서 깨지지 않게

      윈도우와 맥 함께 지원
      
        
      준비 화면, 수업 폴더, 사이드바 화면, 모니터 감지, 화면 위 도구, 녹화, 꾸러미는 한 번 만들면 두 OS에서 함께 동작합니다. OS마다 따로 만드는 것은 창 관리 도우미, 사이드바 고정 방식, 권한 안내, 설치 파일·서명 네 가지입니다.
      
        
      
          
      기능윈도우맥
      
          
            
      창 찾기·앞으로·닫기user32 API, 따로 허용할 권한 없음접근성 API, "손쉬운 사용" 권한 한 번 허용
      
            
      화면 분할SetWindowPos, 모니터 배율 보정접근성 API로 위치·크기, 전체 화면 창은 먼저 해제
      
            
      사이드바 고정AppBar 등록: 다른 창이 사이드바를 덮지 않음항상 위 패널, 분할할 때 사이드바 폭을 빼고 배치
      
            
      PPT 슬라이드 쇼 위 표시최상위 창전체 화면 공간 위에도 보이는 패널 (기술 검증 대상)
      
            
      PPT 시작 슬라이드COM 자동화AppleScript
      
            
      녹화 권한따로 없음"화면 기록" 권한 한 번 허용
      
            
      단축키Ctrl 기준⌘ 기준으로 자동 변환
      
            
      설치 파일설치형 .exe + 설치 없이 실행하는 portable .exe.dmg (Apple Silicon·Intel 겸용)
      
            
      서명미서명이면 첫 실행 때 경고만 (통과 가능)미서명이면 새 버전마다 권한이 풀림 → 자체 서명 인증서로 유지, 나눌 때는 Apple 개발자 등록
      
                
        
      
        
      맥과 윈도우 PC에서 각각 Claude가 같은 GitHub 비공개 저장소로 협업합니다. 맥의 Claude는 공통 코드와 맥 부분을, 윈도우의 Claude는 윈도우 부분을 맡아 그 자리에서 실행하고 고칩니다. 기술 검증은 두 OS 모두 통과해야 다음 단계로 갑니다.
