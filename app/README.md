# 수업 사이드바 — 체험판 (맥·윈도우)

화면 왼쪽에 붙는 사이드바에서 수업 자료를 원래 프로그램(크롬·파워포인트·엑셀·한글·텍스트 편집기/메모장)으로 열고, 앞으로 가져오고, 학생 화면으로 보내고, 나란히 놓고, 닫는 첫 체험판입니다. 맥과 윈도우에서 동작합니다 (윈도우 결과: `docs/poc/windows.md` "체험판으로 확인한 것").

## 설치판 (맥, 더블클릭으로 켜기)
```bash
cd app
npm install                 # 처음 한 번
npm run dist:mac            # 도우미 빌드 + dist/lesson-sidebar-<버전>-mac-arm64.dmg
npm run dist:mac:dir        # 설치 파일 없이 앱만 (dist/mac-arm64/LessonSidebar.app)
npm run smoke:mac           # 만든 앱을 켜서 예시 수업·준비 화면이 열리는지 확인
```
설치하기: `.dmg`를 열고 "수업 사이드바"를 응용 프로그램 폴더로 끌어 놓은 뒤 켭니다.
- 처음 켜면 macOS가 **손쉬운 사용** 권한을 묻습니다. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 "수업 사이드바"를 켜면, 다시 켜지 않아도 2초 안에 창 관리가 시작됩니다.
- 설정은 `~/Library/Application Support/수업 사이드바/`에 저장됩니다. 예시 수업은 그 안의 `체험용 수업` 폴더로 복사해서 씁니다.
- Dock에는 보이지 않습니다. 끄려면 사이드바 아래 "끝내기"를 누릅니다. 앱을 다시 눌러도 사이드바는 하나만 뜹니다.
- 키체인에 자체 서명 코드 서명 인증서 "LessonSidebar Signing"이 있으면 그것으로 서명합니다(`build/sign-local.cjs`). 그러면 새로 설치해도 손쉬운 사용 권한이 남습니다. 인증서가 없으면 아래처럼 임시 서명입니다.
- 지금은 Apple Silicon(M 칩) 맥용만 만들고, 개발자 등록 없이 임시 서명합니다. 그래서 **새 버전을 설치할 때마다 손쉬운 사용 권한을 다시 켜야** 할 수 있습니다. 목록에서 "수업 사이드바"를 끄고 다시 켜거나, −로 지운 뒤 다시 추가합니다. 다른 맥에 옮겨 처음 열 때는 "확인되지 않은 개발자" 경고가 뜹니다. 그때는 앱을 오른쪽 클릭 → 열기를 누릅니다.
- 앱 안쪽 실행 파일 이름은 영어(`LessonSidebar`)입니다. 한글이면 Electron이 켜지다 멈추기 때문입니다. 화면에 보이는 이름은 `build/ko.lproj/InfoPlist.strings`의 "수업 사이드바"입니다.

## 새 버전 올리기 (새 버전 알림이 보는 곳)
1. `app/package.json`의 `version`을 올린다 (예: 0.1.0 → 0.2.0). 맥·윈도우가 같은 번호
2. 맥에서 `npm run dist:mac` (이 맥의 "LessonSidebar Signing"으로 서명해야 설치한 맥들의 권한이 유지된다), 윈도우에서 `npm run dist:win`
3. `gh release create v0.2.0 <dmg> <setup.exe> <portable.exe> --title "0.2.0" --notes "바뀐 것 한 줄"` — 공개 저장소라 누구나 받을 수 있으니 **선생님께 확인받고** 올린다
- 설치판에는 예시 수업만 들어 있다 (선생님 수업·녹화·캡처는 들어가지 않음)

## 설치판 (윈도우, 더블클릭으로 설치·켜기)
```powershell
cd app
npm install                 # 처음 한 번
npm run dist:win            # 도우미 준비 + dist\lesson-sidebar-<버전>-win-setup.exe (설치 파일)
                            #              + dist\lesson-sidebar-<버전>-win-portable.exe (설치 없이 켜는 파일)
npm run dist:win:dir        # 설치 파일 없이 앱 폴더만 (dist\win-unpacked\LessonSidebar.exe)
npm run smoke:win           # 만든 앱을 켜서 도우미·예시 수업·준비 화면이 되는지 확인
```
설치하기: `lesson-sidebar-<버전>-win-setup.exe`를 더블클릭합니다. 물어보는 것 없이 바로 설치되고 사이드바가 켜집니다.
- **관리자 권한이 필요 없습니다.** 내 사용자 폴더(`%LOCALAPPDATA%\Programs\lesson-sidebar`)에 설치되고, 바탕 화면과 시작 메뉴에 "수업 사이드바" 바로 가기가 생깁니다.
- 다른 PC로 옮긴 설치 파일(인터넷·메신저·USB로 받은 파일)을 처음 열면 **"Windows의 PC 보호"**(파란 창, SmartScreen) 경고가 뜰 수 있습니다. 코드 서명(회사 인증서)을 하지 않았기 때문입니다. **"추가 정보"**를 누르면 나오는 **"실행"** 단추를 누릅니다. 보안 설정은 바꾸지 않아도 됩니다. 학교 PC가 이 단추를 막아 두었으면 정보 담당 선생님께 문의하거나 아래 "설치 없이 켜는 파일"을 씁니다 (같은 경고가 뜰 수 있음).
- **설치 없이 켜는 파일** `lesson-sidebar-<버전>-win-portable.exe`: 설치하지 않고 더블클릭으로 바로 켭니다 (USB에 넣어 다니거나 설치가 막힌 PC용). 켤 때마다 임시 폴더에 풀어서 설치판보다 늦게 뜹니다 (이 노트북에서 설치판 약 1초, 설치 없이 켜는 파일 약 9초). 설정은 설치판과 같은 곳에 저장됩니다.
- 설정은 `%APPDATA%\수업 사이드바\`에 저장됩니다. 예시 수업은 그 안의 `체험용 수업` 폴더로 복사해서 씁니다. 개발용(`npm start`, `app\.userdata\`)과 따로라서 **둘을 함께 켜면 사이드바가 두 개** 뜹니다.
- 작업 표시줄에는 보이지 않습니다. 끄려면 사이드바 아래 "끝내기"를 누릅니다. 바로 가기를 다시 눌러도 사이드바는 하나만 뜹니다 (접혀 있으면 펼침).
- 지우기: 설정 → 앱 → 설치된 앱 → "수업 사이드바" → ⋯ → 제거. "LessonSidebar을(를) 제거 하시겠습니까?"(설치 프로그램은 안쪽 영어 이름을 씀)에 확인을 누릅니다. 수업 폴더와 `%APPDATA%\수업 사이드바\`(설정)는 지우지 않으므로 다시 설치하면 그대로 이어집니다.
- 새 버전 설치: 사이드바를 "끝내기"로 끈 뒤 새 설치 파일을 더블클릭합니다. 켜 둔 채 설치하면 "LessonSidebar이(가) 실행 중입니다. OK을 클릭하면 종료됩니다."가 뜨고, OK를 누르면 설치 프로그램이 사이드바에 끄기를 요청하고 1초 뒤에도 남아 있으면 강제로 끕니다. 그러면 "창 비키기"로 옮겼던 창이 제자리로 돌아가지 않을 수 있습니다.
- 창 관리 도우미(`poc/win-helper/winctl.js`와 `koffi`)는 앱 안 `resources\win-helper`에 들어 있고, 앱 실행 파일(`LessonSidebar.exe`)을 Node로 돌려서(`ELECTRON_RUN_AS_NODE`) 실행합니다. 그래서 Electron fuses(실행 파일의 기능 끄기 설정)의 `RunAsNode`를 끄면 안 됩니다 (`package.json`의 `build`에 `electronFuses`를 넣지 않음). `npm run smoke:win`이 이것까지 확인합니다.
- 실행 파일 이름은 맥처럼 영어(`LessonSidebar.exe`)이고, 바로 가기·제거 목록에 보이는 이름은 "수업 사이드바"(`nsis.shortcutName`·`uninstallDisplayName`)입니다. 작업 관리자에는 `LessonSidebar`로 보입니다. 아이콘은 아직 Electron 기본 아이콘입니다.
- 지금은 64비트(x64) 윈도우용만 만듭니다 (ARM 윈도우 노트북에서도 에뮬레이션으로 돌아갈 수 있지만 확인하지 않음).
- `npm install` 때 "allow-scripts" 경고가 나와도 괜찮습니다: `electron-winstaller`(쓰지 않는 다른 설치 방식 Squirrel용)와 `koffi`(미리 만든 파일이 이미 들어 있음)의 설치 스크립트가 막힌 것인데, 이 설치판에는 둘 다 필요 없어 허용하지 않았습니다 (`npm approve-scripts --allow-scripts-pending`으로 목록 확인).

## 실행 (개발용, 맥)
```bash
cd poc && npm run build:mac      # 창 관리 도우미 (처음 한 번)
cd ../app && npm install         # 처음 한 번
npm start
```
- 실행하는 프로그램(터미널 또는 Claude)에 **손쉬운 사용** 권한이 있어야 다른 프로그램 창을 옮길 수 있습니다.

## 실행 (윈도우)
```powershell
cd poc\win-helper; npm install   # 창 관리 도우미 (처음 한 번, koffi 설치)
cd ..\..\app; npm install        # 처음 한 번
npm start
```
- 도우미(`poc/win-helper/winctl.js`)는 Electron 안의 Node로 실행하므로 Node를 따로 설치하지 않아도 됩니다. 권한 설정도 필요 없습니다.
- `npm start`가 "Electron failed to install correctly"로 멈추면 `node node_modules\electron\install.js`를 한 번 실행합니다.
- 진행 메모(.md)는 메모장으로 엽니다. 브라우저는 크롬 → 엣지 → 웨일 순으로 설치된 것을 씁니다.
- 처음에는 `sample-lesson/`(체험용 수업)을 엽니다. "수업 폴더 열기"로 `lesson.json`이 있는 다른 폴더를 열 수 있고, 마지막에 연 폴더를 기억합니다.
- 설정·기록은 개발 중에는 `app/.userdata/`에 둡니다 (저장소에 올리지 않음).

## 수업 준비 (사이드바 아래 "수업 준비")
| 할 일 | 방법 |
|---|---|
| 수업 보관함 정하기 | 처음 한 번: 구글 드라이브 / 문서 폴더 / 다른 위치 중 고르기 (안에 `수업 사이드바` 폴더) |
| 새 수업 | "새 수업" → 이름·날짜 → `날짜_제목` 폴더와 도입·전개·정리 구간이 생김 |
| 파일 넣기 | 창에 끌어다 놓기(놓은 구간에 들어감) 또는 "파일 고르기" — 수업 폴더로 복사, 원본은 그대로, 실행 파일·스크립트는 거름 |
| 링크 넣기 | 붙여 넣으면 유튜브·구글 문서·시트·슬라이드·드라이브·캔바·웹사이트를 알아봄 (유튜브 `t=` 시작 시간도) |
| 메모 | "메모 추가" → "편집"으로 텍스트 편집기에서 고침 (교사 화면에 열림) |
| 고치기 | 자료 이름·시작 위치·띄울 화면, ⋮⋮ 끌어 순서 바꾸기, 구간 이름·시간, ✕ 빼기(파일은 `.sidebar/휴지통`) |
| 정리하기 | 파일 이름 앞 순번과 구간 폴더를 지금 순서에 맞춤 (사이드바에서 열린 파일은 다음에) |
| 이 수업으로 진행 | 사이드바에 바로 반영. 진행 중에 고쳐도 바로 반영 |
| 다른 PC와 함께 | 다른 PC에서 고친 내용은 3초 안에 불러옴, 다른 PC가 열고 있으면 경고 |
| 꾸러미로 내보내기 | 위쪽 버튼 → 먼저 정리하기 → `날짜_제목.zip` 하나로 저장 (USB·메일·동료에게). 잠금·백업·임시 파일·실행 파일은 빼고, 파일 확인값(`.sidebar/manifest.json`)을 넣음. 구글 문서·캔바 링크는 받는 분 권한이 필요하다고 알려 줌 |
| 꾸러미 가져오기 | 왼쪽 아래 버튼 → zip 고르기 → 보관함에 풀고 바로 열림. 같은 수업이 있으면 사본 / 덮어쓰기(예전 것은 보관함의 `.sidebar/덮어쓰기 전`. 윈도우는 그 수업의 파일이 파워포인트 등에 열려 있으면 덮어쓰지 못해 어느 파일인지 알려 줌) / 취소. 위험한 경로·너무 큰 zip은 거절, 실행 파일은 빼고, 손상된 파일은 알려 줌. 드라이브 웹·윈도우 탐색기로 묶은 zip도 됨 |
| 사전 점검 | 위쪽 "사전 점검" → 자료마다 파일(클라우드면 이때 이 PC로 받아 둠)·여는 프로그램·링크(로그인 없이 열리는지, 유튜브 공개 여부), 이 PC의 인터넷·브라우저·모니터·창 제어 권한·저장 공간·다른 PC를 확인. 문제 → 주의 → 정상 순서로 보여 줌. 꾸러미를 가져오면 자동으로 한 번 |
| 저장 | 저장 버튼 없음. 바꿀 때마다 바로 저장. 글자 칸은 치다 1.2초 멈추면 · Enter나 다른 곳을 누르면 · 다른 창으로 가면 · 창을 닫거나 끝내면 저장. 백업(`.sidebar/backup`)은 1분에 하나, 최근 10개 (다른 PC에서 바뀐 파일을 덮을 때는 먼저 백업) |
- 수업 후 돌아보기: 준비 화면 맨 아래 글 칸 (자동 저장, 지난 수업 검색에 잡힘, 안내 페이지·복제본에는 안 들어감)
- 웹 자료 저장본: 웹사이트 링크의 "PDF 저장본" → 페이지를 PDF로 찍어 링크 바로 아래에 넣는다 (인터넷이 끊겼을 때 대비)

## 할 수 있는 것 (사이드바)
사이드바 아래: 발표 도구 아이콘 묶음(포인터 강조·스포트라이트·판서 펜·확대·캡처 핀) | 수업 진행 아이콘 묶음(녹화·발표자 화면·휴대폰 리모컨), 창 정리 묶음(미리 열기·다른 창 숨김·모두 닫기), 수업 준비·끝내기. 아이콘에 마우스를 올리면 이름과 설명이 뜬다. 앱 아이콘은 `build/icon.svg`를 고친 뒤 `npm run icon`.

| 동작 | 방법 |
|---|---|
| 자료 열기 / 앞으로 가져오기 | 목록 누르기 (듀얼 모니터면 학생 화면에, 진행 메모는 교사 화면에) |
| 교사 화면에서 먼저 보기 | 위쪽 "여는 곳"에서 "교사 화면에서 먼저" → 확인 후 ⇄ |
| 다른 화면으로 보내기 | 열린 자료에 마우스를 올리고 ⇄ |
| 닫기 | ✕ (저장 확인 창 등이 뜨면 그 창을 앞으로 가져오고 "답 기다림" 표시). 윈도우 11 메모장은 창을 닫지 않고 진행 메모 탭만 닫음 — 사이드바가 연 창이면 바로, 선생님이 열어 둔 메모장이면 안내 옆 "사이드바에서 이 탭만 닫기" 단추로 |
| 나란히 보기 | 자료 왼쪽 네모를 눌러 2~4개 고르기 → 아래에서 배치 고르기 (2개 반반·7:3·3:7, 3개 3분할·큰 화면+2, 4개 4분할). 듀얼이면 학생 화면에. 창 사이 노란 막대를 끌면 폭·높이가 바뀜(놓을 때 옮김). "이 배치 수업에 저장"하면 아래 "저장한 배치"에서 한 번에 다시 놓음. "원래대로"로 풀기 |
| 다음 자료 | 위쪽 "다음" |
| 모두 미리 열기 | 아래 버튼 — 학생 화면에는 첫 자료만 보이고 나머지는 최소화 |
| 다른 창 숨기기 | 학생 화면에서 지금 자료만 남기기 |
| 포인터 강조 · 스포트라이트 | 사이드바 아래 단추. 포인터: 커서 주변 노란 원, 누르면 물결(도우미 `clicks`), 클릭은 그대로 아래 프로그램에. 스포트라이트: 화면을 어둡게 하고 커서 주변만 밝게, 휠로 크기, Esc·두 번 누르기로 끄기. 모든 화면·슬라이드 쇼 위에 겹쳐 보임 |
| 판서 펜 | 사이드바 아래 연필 아이콘 → 모든 화면 위에 그림판. 아래 막대: 색 6가지, 펜·형광펜·지우개(선 단위), 굵기 3단계, 되돌리기, 모두 지우기, 저장(판서가 보이는 화면을 수업 폴더 `_캡처/판서_….png`로, 화면 기록 권한), ✕. 막대는 왼쪽 점을 끌어 옮긴다. 사이드바에서 다른 자료로 넘어가거나 펜을 끄면(Esc·✕·아이콘) 지워진다. 터치·펜 화면에서도 그린다 |
| 단축키 | Ctrl+Alt(맥 ⌃⌥)+N 다음 · B 이전 · K 가리기 · F 정지 · P 판서 펜 · L 포인터 · S 스포트라이트 · Z 확대. 어느 프로그램이 앞에 있어도 된다. ⚙에서 끄고 켜기 |
| 링크 QR | 링크 자료에 마우스를 올리면 "QR" → 학생 화면에 큰 QR. 누르거나 Esc로 닫기 |
| 확대 · 캡처 핀 | 사이드바 아래 단추 (맥 "화면 기록" 권한 필요). 확대: 커서가 있는 화면을 멈추고 2배, 휠로 1.5~4배, 클릭·Esc로 끝. 캡처 핀: 끌어서 고른 부분을 항상 위 작은 창으로 고정(끌어 옮기기, ✕), 수업 폴더 `_캡처/`에 저장. "핀 닫기"로 모두 닫기 |
| 학생 화면 정지 · 가리기 · 미리보기 | 듀얼이면 사이드바 위쪽 "정지"(지금 장면으로 멈춤, 뒤에서 창 정리)·"가리기"(검은 화면 "잠시 후 계속합니다")·"미리보기"(학생 화면을 작게, 저장 안 함). 다시 누르면 풀림. 모니터 한 대면 "화면 가리기"만. 화면 기록 권한 필요(정지·미리보기) |
| 녹화 | 아래 "● 녹화" → 학생 화면(모니터 한 대면 이 화면)을 MP4로, 위쪽 빨간 막대에 경과 시간 · "녹화 끝내기" → 수업 폴더 `_녹화/`에 저장 + 자료를 바꿀 때마다 남긴 목차(`_목차.txt`). 설정에서 마이크·가볍게(720p) 선택. 앱이 갑자기 꺼져도 다음에 켤 때 복구. 화면 기록 권한 필요 |
| 지난 수업 찾기 · 복제 | 수업 준비 화면 왼쪽 "지난 수업 찾기"(수업·자료 이름, 링크 주소) · 위쪽 "복제" → 새 이름·날짜로 자료·순서·메모를 복사 (녹화·캡처는 빼고) |
| 안내 페이지 | 수업 준비 화면 "안내 페이지" → 수업 폴더에 `수업안내.html` (순서와 링크, 진행 메모는 빠짐). 참여자에게 나눠 주기 |
| 충돌 사본 고르기 | 두 PC에서 같은 수업을 동시에 고쳐 `lesson (1).json` 같은 사본이 생기면 보관함에 "충돌 사본" 표시, 수업 준비 화면 위쪽에서 쓸 것을 고름 (나머지는 `.sidebar/backup`) |
| 발표자 화면 | 아래 "발표자 화면" → 교사 화면에 큰 창: 진행 메모(지금 구간), 수업·구간 시계(구간에 머문 시간을 더함, 계획을 넘으면 빨강), 지금·다음 자료와 다음 자료 창 미리보기(미리 열려 있고 화면 기록 권한이 있을 때), 이전·다음 단추. 키보드 → 다음, ← 이전 |
| 휴대폰 리모컨 | 아래 "휴대폰 리모컨" → QR을 휴대폰 카메라로 찍기 (이 PC와 같은 와이파이). 다음·이전, 자료 고르기, 정지·가리기, 진행 메모 보기. 휴대폰이 붙으면 QR은 접힘, "새 주소"를 누르면 연결했던 휴대폰은 끊김. 학교 와이파이가 기기끼리 연결을 막으면 안 됨 (휴대폰 핫스팟에 PC를 붙이면 됨) |
| 새 버전 알림 | 하루 한 번 GitHub에 올린 새 설치판을 확인해 사이드바 위에 "내려받기" (설정에서 끄기·지금 확인). 깔기는 직접: 사이드바를 끝내고 받은 설치 파일로 덮어 설치 |
| 사이드바가 연 창 모두 닫기 | 아래 버튼을 두 번 → 사이드바가 연 창(열 때 함께 생긴 창 포함)을 정상 닫기로 모두 닫음. 선생님이 원래 열어 둔 창은 그대로, 저장할지 묻는 창은 "답 기다림" |
| 브라우저 업데이트 대기·겹침 | 크롬·엣지·웨일이 업데이트 뒤 다시 시작을 기다리거나 두 개 켜져 있으면 하나 더 띄우지 않고 켜진 브라우저에 탭으로 열고, 상황에 맞게 알림 (프로필 문제·로그인 풀림 예방) |
| 자동 숨김 | 오른쪽 위 버튼 — 접히면 교사 화면 왼쪽 가운데에 반투명 노란 막대(손잡이)만 남음 (막대 자리 클릭은 아래 창으로 감). 교사 화면 왼쪽 끝에 마우스를 대면 나타남. 왼쪽에 학생 화면이 있으면 막대 높이에서 왼쪽으로 넘어가도 나타남 |
| 설정 (⚙) | 펼친 사이드바 투명도 (불투명·90·80·70%, 배경만 비치고 글씨는 그대로). "고정해 둘 때 가려지는 창을 옆으로 비키기"(윈도우·맥, 기본 꺼짐. 맥은 고정해 둔 동안 2초마다 새로 가려진 창도 비킴. 자동 숨김을 켜면 이 설정은 꺼지고, 자동 숨김 중에 켜면 사이드바가 고정됨) — 교사 화면에서 사이드바에 가려지는 창(선생님 창 포함)을 오른쪽으로 옮기고, 자동 숨김·설정 끄기·끝내기 때 돌려놓음 (펼치고 접는 순간에만 동작, 고정해 둔 동안 새로 연 창은 그대로) |
| 모니터 연결이 바뀔 때 | 학생 화면이 빠지면 창을 교사 화면으로 모으고, 다시 꽂으면 돌려놓음 |
| 다시 켰을 때 | 이미 열린 문서 창(PPT·엑셀·한글·메모)을 다시 연결 |

## 시험
```bash
npm test                                 # 수업 진행 로직 (가짜 도우미, 창을 열지 않음)
SIDEBAR_DEBUG=1 npm start                # 개발용 원격 조작 주소를 .userdata/debug.json에 남김
```
윈도우 PowerShell에서는 `$env:SIDEBAR_DEBUG='1'; npm start`.
원격 조작: `GET <debug.json의 url>/act?do=activate&arg=it4` → 동작 후 상태(JSON). `do`는 `activate, move, close, closeTab, toggleSel, split, untile, openAll, next, hideOthers, openTo, autoHide, opacity(100·90·80·70), aside(true·false)`.
