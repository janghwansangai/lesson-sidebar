한글 · 파워포인트 · PDF · 웹사이트 · 유튜브를 수업 순서대로 모아 두고, 화면 왼쪽 사이드바에서 누르기만 하면 열고 · 학생 화면에 띄우고 · 닫습니다. 판서 펜 · 확대 · 녹화 · 휴대폰 리모컨까지, 선생님이 만든 무료 프로그램입니다.

수업 순서대로 한곳에

수업 하나가 폴더 하나. 파일을 끌어다 놓고 도입 · 전개 · 정리로 나눠 두면, 수업 중에는 위에서부터 누르기만 하면 됩니다.

누르면 학생 화면에

모니터 두 대(교사 화면 + 프로젝터)를 기본으로 생각했습니다. 자료를 누르면 열고, 이미 열려 있으면 앞으로 가져와 학생 화면에 띄웁니다.

학생 화면을 내 마음대로

정지(지금 장면으로 멈춤) · 가리기('잠시 후 계속합니다') · 미리보기(사이드바에서 학생 화면을 작게)로, 창을 정리하는 모습을 보이지 않을 수 있습니다.

발표 도구

포인터 강조(누르면 물결) · 스포트라이트 · 판서 펜 · 확대 · 캡처 핀. 파워포인트 슬라이드 쇼 위에서도 됩니다.

녹화와 목차

학생 화면을 녹화하고, 띄운 자료가 바뀐 시각을 목차로 남깁니다. 1시간마다 나눠 저장하고, 갑자기 꺼져도 다음에 켤 때 살립니다.

휴대폰 리모컨 · 발표자 화면

같은 와이파이의 휴대폰으로 QR만 찍으면 다음 · 이전 · 가리기. 교사 화면에는 진행 메모와 구간 시계를 크게.

설치하기

맥 (Apple Silicon)

  1. 위의 맥용 내려받기로 받은 .dmg를 엽니다.
  2. 수업 사이드바를 응용 프로그램 폴더로 끌어 옮긴 뒤 그곳에서 켭니다. 설치 파일 창에서 바로 켜지 마세요.
  3. 시스템 설정 → 개인정보 보호 및 보안에서 '수업 사이드바'를 켭니다.
    • 손쉬운 사용: 자료 창을 찾고 · 옮기고 · 닫는 데 꼭 필요
    • 화면 및 시스템 오디오 기록: 미리보기 · 정지 · 확대 · 캡처 핀 · 녹화
    • 마이크: 녹화에 목소리를 담을 때만
  4. 처음 열 때 "확인되지 않은 개발자"가 뜨면 앱을 오른쪽 클릭 → 열기.

윈도우 10 · 11

  1. 윈도우용 내려받기로 받은 설치 파일을 실행하면 바로 설치되고 켜집니다 (관리자 권한 필요 없음).
  2. 'Windows의 PC 보호' 창이 뜨면 추가 정보 → 실행을 누릅니다.
  3. 설치가 막힌 학교 PC는 설치 없이 쓰는 윈도우 파일을 바로 실행합니다.
  4. 휴대폰 리모컨을 처음 켤 때 'Windows 보안 경고'가 뜨면 액세스 허용.

새 버전이 나오면 사이드바 위에 업데이트가 뜹니다. 누르면 받아서 바꿔 깔고 다시 켭니다 (0.3.2부터).

메뉴별 사용법

① 사이드바 위쪽

? 도움말
앱 안의 도움말 창. 사용 방법, 문제 해결, 업데이트 확인, 오류 신고.
⚙ 설정
투명도, 녹화, 단축키, 새 버전, 창 비키기 (아래 ⑧).
자동 숨김
사이드바를 접어 화면 왼쪽 가운데 노란 막대만 남깁니다. 왼쪽 끝으로 마우스를 밀면 다시 나옵니다.

② 수업 · 학생 화면

여는 곳
학생 화면에 바로 띄우거나, 교사 화면에서 먼저 열어 확인한 뒤 보냅니다.
정지
학생 화면을 지금 장면으로 멈춥니다. 그동안 창을 정리해도 학생에게는 보이지 않습니다.
가리기
학생 화면을 '잠시 후 계속합니다'로 가립니다.
미리보기
학생 화면을 사이드바에 작게 보입니다. 누르면 바로 새로 찍습니다.
다음
다음 자료를 엽니다.

③ 자료 목록

자료 누르기
열고(이미 열려 있으면 앞으로) 정한 화면에 띄웁니다.
⇄ · ✕
열린 자료에 마우스를 올리면 보입니다. 학생 화면 ↔ 교사 화면 옮기기, 닫기.
QR
링크 자료에 마우스를 올려 누르면 학생 화면에 큰 QR이 뜹니다.
고르기 칸
2~4개를 골라 나란히 보기(반반 · 7:3 · 3분할 · 큰 화면+2 · 4분할). 창 사이 노란 막대로 폭을 바꾸고, 이 배치 수업에 저장하면 다음에 한 번에 다시 놓습니다. 필요 없는 배치는 ✕.

④ 발표 도구 (아래 왼쪽 아이콘)

포인터 강조
커서 둘레에 노란 원, 누르면 물결. 클릭은 그대로 아래 프로그램에.
스포트라이트
커서 둘레만 밝게. 휠로 크기, Esc로 끄기.
판서 펜
화면 위에 그리기. 색 · 굵기 · 형광펜 · 지우개 · 되돌리기 · 저장(수업 폴더 _캡처). 다른 자료로 넘어가면 지워집니다.
확대
화면을 멈춰 커서 둘레를 크게. 사이드바 단추는 학생 화면을 확대합니다. 휠로 배율, 클릭 · Esc로 끝.
캡처 핀
끌어서 고른 부분을 항상 위에 떠 있는 작은 창으로 고정하고 저장합니다.

⑤ 수업 진행 (아래 오른쪽 아이콘)

녹화
학생 화면(설정에서 교사 화면)을 녹화. 끝나면 수업 폴더 _녹화에 영상과 목차. 1시간마다 _1부 · _2부로 나눠 저장합니다. 가리거나 정지한 동안에는 녹화에도 학생이 보는 화면이 담깁니다. 학생 얼굴 · 목소리 · 이름이 담길 수 있으니 공유 전에 꼭 확인하세요.
발표자 화면
교사 화면에 지금 · 다음 자료, 진행 메모, 수업 · 구간 시계를 크게.
휴대폰 리모컨
사이드바에 뜬 QR을 휴대폰으로 찍으면 다음 · 이전 · 정지 · 가리기. PC와 같은 와이파이여야 합니다.

⑥ 창 정리 (맨 아래)

미리 열기
수업 전에 자료를 모두 열어 둡니다. 학생 화면에는 첫 자료만.
다른 창 숨김
학생 화면에서 지금 자료만 남기고 최소화.
모두 닫기
두 번 누르면 사이드바가 연 창만 닫습니다 (선생님이 원래 열어 둔 창은 그대로).
수업 준비 · 끝내기
수업 준비 화면을 열고, 사이드바를 끕니다.

⑦ 수업 준비 화면

수업 보관함
수업 폴더들이 모이는 곳. 구글 드라이브 안에 두면 맥 · 윈도우에서 함께 씁니다.
새 수업 · 다른 폴더 열기
수업을 새로 만들거나, 다른 곳의 수업 폴더를 엽니다.
자료 넣기
파일을 창에 끌어다 놓거나 파일 고르기, 유튜브 · 웹 주소는 링크 추가, 진행 메모는 메모 추가. 넣은 파일은 수업 폴더로 복사됩니다.
구간 · 순서
구간 추가로 도입 · 전개 · 정리를 나누고 시간을 적습니다. 자료는 끌어서 순서를 바꿉니다.
시작 위치 · 띄울 화면
영상 0:45, PDF 3쪽, 3번 슬라이드처럼 시작 위치를, 자료마다 학생 · 교사 화면을 정합니다.
사이드바에 반영
고친 수업을 바로 사이드바에서 씁니다.
사전 점검
수업 전에 프로그램 · 링크 · 파일이 다 열리는지 미리 봅니다.
정리하기
자료 파일 이름을 수업 순서대로 정리합니다.
복제
지난 수업을 복사해 '2차 연수'를 만듭니다 (녹화 · 캡처는 빼고).
안내 페이지
참여자에게 나눠 줄 자료 목록 페이지(인터넷 없이 열림).
꾸러미
수업을 파일 하나로 내보내고 가져옵니다.
PDF 저장본
웹 자료를 PDF로 저장해 두어 인터넷이 안 될 때 대신 띄웁니다.
수업 후 돌아보기
맨 아래에 다음 수업을 위한 메모를 남깁니다.

녹화

문제가 생겼을 때

휴대폰 리모컨: "웹페이지가 일시적으로 다운되었거나…"가 나와요

휴대폰 브라우저에 주변 기기(로컬 네트워크) 권한이 없으면 같은 와이파이의 PC에도 들어가지 못합니다.

  1. 안드로이드: 설정 → 애플리케이션 → Chrome → 권한 → 주변 기기 → 허용
  2. 아이폰: 설정 → Chrome(또는 쓰는 브라우저) → 로컬 네트워크 켜기
  3. 사이드바의 QR을 다시 찍습니다.
휴대폰 리모컨: "연결을 거부했습니다"가 나와요

PC의 와이파이가 바뀌어 주소가 달라졌는데 예전 QR을 찍은 경우입니다. 사이드바에 새로 뜬 QR을 다시 찍어 주세요.

휴대폰 리모컨: 같은 와이파이인데도 안 돼요
  1. 휴대폰이 모바일 데이터로 접속 중일 수 있습니다. 비행기 모드를 켠 뒤 와이파이만 다시 켜세요.
  2. 휴대폰의 VPN · 보안 Wi-Fi를 끕니다.
  3. 학교 와이파이는 기기끼리 연결을 막아 둔 경우가 많습니다. 휴대폰 핫스팟에 PC를 연결한 뒤 QR을 다시 찍으세요.
  4. 윈도우: 처음 켤 때 'Windows 보안 경고'를 취소했다면 학교 전산 담당께 방화벽 허용을 부탁합니다.
사이드바가 자료 창을 찾거나 옮기지 못해요 (맥)

시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 '수업 사이드바'가 켜져 있는지 보세요. 켜져 있는데도 안 되면 껐다 다시 켜고, 사이드바도 다시 켭니다.

미리보기 · 확대 · 녹화가 검게 나와요 (맥)

시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 기록에서 '수업 사이드바'를 켜고 사이드바를 다시 켭니다. 화면이 잠겨 있는 동안에는 화면을 찍을 수 없습니다.

컴퓨터가 느려졌어요

사이드바 안내에 '정리하기'가 보이면 눌러 주세요 (지난번에 꺼지지 않은 조각 정리). 맥은 설치 파일(.dmg) 창에서 바로 켜지 말고 응용 프로그램 폴더에서 켜 주세요.

여기에 없는 문제는 오류 신고로 알려 주세요. 프로그램 안의 도움말(사이드바 위 ?)에도 같은 안내가 있습니다.
